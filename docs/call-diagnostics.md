# История звонка и актуальность уведомлений

Диагностика версии 2 дополняет прежний список RTC-счётчиков локальной историей последних 120 секунд, максимум 180 событий. События заданы перечислением; дополнительные значения допускают только конечные неотрицательные числа RTT, потерь и количества участников. Имена, id звонков/чатов/устройств, адреса, SDP, ключи и тексты ошибок в историю не записываются. Сервер историю не получает.

Во время личного звонка отмечаются захват устройств, соединение, сигналинг, смена сети, ICE restart, mute, качество, ошибки разрешения и таймаут. Для группы отмечаются вход, захват, сигналинг, mute и переподключение SDK. При завершении сохраняется технический отчёт; его можно скачать в настройках до перезагрузки окна. Старый асинхронный getStats не перезаписывает отчёт нового звонка. Выход и сброс локальных данных очищают отчёт и отменяют запоздавшее сохранение.

## Уведомления

Перед показом звонка service worker запрашивает `GET /api/chats/{id}/call-status?call=<точный id>`. Маршрут доступен только активному устройству участника чата, не кешируется и не раскрывает содержимое сигналинга. Учитываются срок ожидания, замена/ответ личного вызова, id групповой комнаты и уже присоединившийся пользователь.

Только подтверждённый отрицательный ответ подавляет входящий вызов. При сбое сети, таймауте или ошибке сервера сохраняется обычный звонок со звуком и действиями: слабая сеть не должна прятать настоящий вызов. Для уже не ожидающего ответа вызова убирается только его собственное уведомление. Safari/Firefox требуют видимого уведомления при push: актуальное более новое уведомление сохраняется без повторного звука; если его нет, показывается нейтральная запись без «Ответить». Она закрывается при получении итога звонка или открытии приложения.

Push обрабатываются последовательно. `callEnd` содержит id и не закрывает следующий звонок. «Ответить» и «Присоединиться» открывают или фокусируют окно до сетевой проверки, сохраняя короткое разрешение Firefox на открытие окна. Подтверждённый неактивный вызов не принимается, неизвестный статус сохраняет намерение. «Отклонить» отправляет точный id серверу без предварительного запроса. События ответа/отклонения несут id и чат, а страница сверяет их со своим входящим вызовом. Новая открытая страница также получает действие после проверки. Заметка `gjoin` привязана к id комнаты и сохраняется, пока старый список звонков не обновлён: старое нажатие не присоединяет к следующей комнате того же чата. Прежняя структура ключей IndexedDB и шифротекст не меняются.

Зашифрованный итог звонка не содержит id личного вызова и может прийти с задержкой. Он закрывает только уведомление того же чата, чей точный id сервер подтвердил как неактивный. При offline или живом новом вызове уведомление сохраняется; сам итог отображается как обычное сообщение.

## Проверка

- Регрессии сервера: чужой чат, живой/заменённый/просроченный вызов, другой id группы и уже присоединившийся пользователь.
- Регрессии service worker: живой вызов, запоздавший push, offline, старый callEnd поверх нового звонка, одновременные push/end и действия старого уведомления.
- Реальная машина состояний страницы: старое уведомление не принимает и не отклоняет новый вызов.
- Браузерный прогон с настоящими WebRTC/LiveKit: декодирование, падение Go и SFU, освобождение ресурсов; после завершения скачана история с signaling-close/open/ended и проверено отсутствие имён, адресов и SDP.

Физические телефоны и доставка через Apple/Mozilla остаются ручной проверкой. Автотест service worker проверяет его настоящий код с заменой только браузерных границ, без отправки push на пользовательские устройства.
