# Как поставить Нитку на компьютер

Установщики раздаёт ваш сервер: на экране входа и в Настройках → «Приложения» (их выкладывает владелец сервера, `docs/apps.md`). Приложение без платной подписи, поэтому система предупредит при установке. Это ожидаемо: контрольная сумма каждого файла лежит в `SHA256SUMS.txt` на том же сервере.

## Windows

1. Скачайте `Thread-Setup-<версия>.exe` и запустите.
2. Если появится «Windows защитил ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».
3. Установка идёт без прав администратора, только для вас. Нитка откроется сама и останется в трее рядом с часами.
4. Если антивирус удалил файл или поместил его в карантин, восстановите его и добавьте в исключения. Новую версию можно отправить в Microsoft на проверку ложного срабатывания.

## macOS

1. Скачайте DMG под свой Mac:
   - `Thread-<версия>-arm64.dmg`: Apple Silicon (M1 и новее);
   - `Thread-<версия>-x64.dmg`: Intel.
2. Откройте DMG и перетащите значок Thread в «Программы».
3. Запустите Нитку. macOS скажет, что не может проверить разработчика, и не откроет её. Это нормально.
4. Откройте «Системные настройки» -> «Конфиденциальность и безопасность». Внизу будет строка про Thread: нажмите «Всё равно открыть» и подтвердите паролем. Кнопка видна около часа после попытки запуска; если её нет, запустите Нитку ещё раз.
5. Если macOS пишет «Thread повреждён», выполните в Терминале и запустите снова:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Thread.app
   ```

6. При первом звонке разрешите микрофон и камеру. Для показа экрана разрешите запись экрана: «Конфиденциальность и безопасность» -> «Запись экрана и системного звука».
7. После обновления macOS может снова спросить разрешения: приложение подписано без сертификата Apple, и система видит новую версию как новую программу.

## Linux

- Ubuntu и Debian: `sudo apt install ./Thread-<версия>-amd64.deb`.
- Другие системы: `Thread-<версия>-x86_64.AppImage`. Сделайте файл исполняемым и запустите. Если на Ubuntu 24.04 и новее AppImage не стартует, поставьте deb: так песочница Chromium работает без ручной настройки.
