# Нитка на Android

Приложение раздаётся файлом APK с вашего сервера, без Google Play: экран входа или Настройки → «Приложения». Оно подписано ключом владельца сервера: обновление ставится поверх, переписка остаётся.

## Поставить на телефон

1. Скачать `Thread-<версия>.apk` на экране входа или в Настройках → «Приложения».
2. Открыть файл. Android попросит разрешить установку из этого источника (браузера или «Файлов»): разрешить и вернуться назад.
3. Play Protect может предупредить о неизвестном разработчике: «Подробнее» → «Всё равно установить».
4. При первом запуске разрешить уведомления. На Android 14 и новее приложение попросит ещё «Полноэкранные уведомления»: без них входящий звонок придёт обычным уведомлением, а не на весь экран поверх блокировки.
5. Войти как обычно, паролем. Микрофон и камеру приложение спросит при первом звонке.

Обновление: в приложении появится «Вышла версия X» с кнопкой «Обновить» (`docs/updates.md`).

## Что умеет приложение

- Уведомления о сообщениях с текстом и звонки на весь экран, даже когда приложение закрыто: сервер шлёт их через Firebase Cloud Messaging. Google видит только время и размер, текст расшифровывается на телефоне.
- Звонок продолжается с выключенным экраном и в другом приложении: на это время включается служба с уведомлением «Идёт звонок». Видеозвонок сворачивается в маленькое окно.
- Файлы сохраняются в «Загрузки».
- Показать свой экран с Android пока нельзя, смотреть чужой можно.

Собрать приложение под свой сервер (адрес, Firebase, ключ подписи): `docs/apps.md`.
