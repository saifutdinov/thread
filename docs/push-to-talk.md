# Назначаемая клавиша микрофона

В настройках приложения и звонка можно включить «Нажми, чтобы говорить» и записать свою клавишу или комбинацию. По умолчанию используется пробел. Нажмите кнопку записи, затем сочетание; Esc отменяет запись. Настройка сохраняется только в этом браузере. Клавиши определяются по физическому положению, например Ctrl+Shift+V, независимо от языка ввода. Модификаторы без основной клавиши не назначаются.

В активном окне браузера это работает на Windows, macOS и Linux без установки. Ввод в текстовых полях не открывает микрофон. Кнопка микрофона и кнопка в плавающем окне продолжают работать независимо от сочетания. Отпускание клавиши или необходимого модификатора выключает микрофон; уход фокуса отпускает клавишу активного окна. После отключения режима микрофон включается вручную.

## Поверх игры на Windows

Для Chrome и Edge добавлен отдельный небольшой компаньон. Страница остаётся в браузере, компаньон сообщает только состояние назначенного сочетания через Native Messaging. Он не получает аудио, переписку, идентификаторы звонков, не отправляет сетевые запросы и не сохраняет нажатия. Автозапуска и службы нет: браузер запускает процесс при активном звонке с включённой глобальной клавишей и завершает при отключении.

Комплект пока устанавливается из исходников, публикации в магазинах и подписанного установщика нет:

1. Собрать на Windows из корня репозитория с Go версии из `go.mod`:

   ```powershell
   go build -ldflags '-H=windowsgui' -o desktop/thread-hotkeys.exe ./cmd/thread-hotkeys
   ```

2. В `desktop/extension/manifest.json` и `desktop/extension/origins.js` заменить `https://chat.example.org` адресом своего сервера. Открыть `chrome://extensions` или `edge://extensions`, включить режим разработчика и выбрать «Загрузить распакованное расширение», указав каталог `desktop/extension`. Зафиксированный открытый ключ в manifest сохраняет ID `gpllklapodoigknihafpbaikjcndiioe`.
3. Зарегистрировать компаньон для текущего пользователя Windows:

   ```powershell
   .\desktop\thread-hotkeys.exe install gpllklapodoigknihafpbaikjcndiioe
   ```

   Появится результат установки. Права администратора и изменение политики выполнения PowerShell не требуются. Бинарник и manifest копируются в `%LOCALAPPDATA%\ThreadHotkeys`; регистрация создаётся в HKCU для Chrome и Edge. Чужую регистрацию с тем же именем установщик отказывается заменять. Перед обновлением завершите звонки и закройте браузер, чтобы он отпустил исполняемый файл.

4. Обновить страницу Нитки. Включить «Нажми, чтобы говорить» и «Говорить поверх других приложений», выбрать сочетание. Во время звонка должен появиться статус «Компаньон подключён». Для повторного подключения есть отдельная кнопка.

Расширение разрешает только адрес из manifest и `origins.js`, без localhost. Для локальной разработки запустите `node desktop/make-dev-extension.mjs` из корня и загрузите отдельно `desktop/.extension-dev`: только эта сборка допускает localhost:8080/5173/8086. Она не предназначена для раздачи. Native manifest разрешает только указанный ID расширения. Открытый key фиксирует ID распакованной сборки, но не доказывает её авторство: загружайте только проверенные файлы, другой распакованный код с тем же key получает тот же ID.

Одна вкладка владеет глобальным сочетанием; другая получает понятный статус занятости. При новом звонке, смене сочетания или восстановлении соединения сначала нужно отпустить уже удерживаемую клавишу. Сообщения прошлого соединения не могут открыть микрофон: на каждое подключение создаётся новый случайный маркер. Разрыв native-соединения отпускает микрофон сразу после доставки события, потеря heartbeat обнаруживается страницей за 1,5 секунды. При заморозке страницы отключается глобальный источник; после возобновления требуется новое нажатие. Общая потеря исполнения браузера/ОС не даёт гарантий времени обработки.

Компаньон опрашивает выбранное сочетание раз в 20 мс, пока оно включено, и не перехватывает ввод у игры. Системные зарезервированные сочетания, защищённый рабочий стол, некоторые игры и античиты могут ограничить работу. Тесты подтвердили ввод без фокуса на Нитке; запуск в каждой игре, полноэкранном режиме и с каждым античитом отдельно не проверен.

Для удаления отключите глобальную клавишу, удалите расширение и закройте браузеры. Из папки с исходной полученной копией выполните `.\thread-hotkeys.exe uninstall`. Команда сначала проверяет, что значения HKCU Chrome/Edge указывают на наш manifest; чужая регистрация вызывает отказ до изменений. Удаляются только свои ключи и известные файлы, каталог не удаляется рекурсивно. При запуске из самого установленного exe Windows удерживает его открытым: после завершения каталог `%LOCALAPPDATA%\ThreadHotkeys` можно удалить вручную. Повторное удаление допустимо. Установка не меняет регистрации других пользователей.

В приложении кнопка «Как установить компаньон» открывает инструкцию RU/EN локально. Владелец сервера передаёт участникам проверенные exe и папку расширения. Глобальный пробел срабатывает при наборе текста в любой программе; выберите отдельное сочетание. Модификаторы точные, поэтому дополнительный Shift отпускает и обычный пробел. Tab не назначается и выходит из записи с переходом фокуса, стрелки и Home/End/PageUp/PageDown требуют модификатор.

Хост и расширение независимо запрещают менять сочетание чаще раза в секунду; переподключение native-процесса не обходит лимит расширения. Слишком быстрая смена требует отпустить клавиши и повторить подключение через секунду. Настройка того же сочетания и mute не ограничиваются. Граница доверия и ограничения при XSS описаны в [ADR 0005](adr/0005-global-push-to-talk.md).

## Другие платформы

На macOS и Linux назначаемое сочетание работает в активном окне. Глобальный backend пока реализован только для Windows; интерфейс не предлагает недействующий переключатель на других ОС. Для macOS понадобится отдельный backend и разрешение «Мониторинг ввода», для Linux поведение зависит от X11/Wayland. Протокол браузера и расширения можно переиспользовать, но такая поддержка требует проверки на самих платформах. Safari и Firefox пока не поддерживаются компаньоном.

## Проверки

- `cd web; npm test`: точные модификаторы, сохранённые некорректные настройки, отпускание во время IME, auto-repeat после потери фокуса, независимое удержание в PiP, heartbeat, старые маркеры, единственный владелец и ошибки native-протокола.
- `go test -race ./...`: ограничение кадров Native Messaging, неизвестные команды, повторное взведение после отпускания, остановка при EOF. Windows-тест установки использует временный отдельный каталог и отдельную ветку HKCU, удаляемую после проверки.
- CI собирает Windows-бинарник из Linux и запускает тесты протокола/установки и сборку на Windows.
- Дополнительная ручная автоматизация на Windows проверила реальное расширение, Native Messaging, системный ввод Ctrl+Shift+F24 без фокуса на Нитке и выключение микрофона при разрыве порта. Временная регистрация после проверки удалена.
- Опциональная проверка системного ввода: `$env:THREAD_HOTKEY_INPUT_TEST='1'; go test ./cmd/thread-hotkeys -run TestWindowsGlobalKeyState -count=1`. Она коротко посылает Ctrl+Shift+F24 текущему рабочему столу; запускайте отдельно от работы/игры.

Аудиоканал, E2EE, сервер и протокол звонков не меняются.
