# Нитка

[English](README.md) | [Русский](README.ru.md)

**Связующая нить для своих.** Нитка - чат для семьи и близких друзей со сквозным шифрованием, который вы запускаете на своём сервере. Работает в любом современном браузере на телефоне, планшете и компьютере и ставится на главный экран как обычное приложение. Без номеров телефонов, магазинов приложений и без посредников, которые могут прочитать ваши сообщения.

## Возможности

- **Свой сервер, свой круг.** В чат попадают только по одноразовым ссылкам-приглашениям, которые создаёте вы или ваши близкие. Вход по сгенерированному запоминающемуся паролю и с подтверждением на одном из ваших устройств. Забыли пароль? Тот, кто вас пригласил, пришлёт ссылку восстановления. Того, у кого уже есть аккаунт, добавляют ссылкой «В друзья»: по ней можно только войти.
- **Сквозное шифрование.** Сообщения, фото, файлы, голосовые, реакции, названия групп и аватары шифруются на устройствах, сервер хранит только шифротекст. Коды безопасности позволяют проверить, что никто не добавил и не подменил устройства собеседника.
- **Переписка:** личные чаты и группы, ответы, реакции, форматирование, редактирование и удаление, пересылка, закреплённые сообщения, поиск на устройстве, предпросмотр ссылок (выключен по умолчанию), ответ свайпом.
- **Медиа:** фото (геометка и прочие метаданные удаляются), видео, файлы до 50 МБ, голосовые (до 5 минут) с выбором скорости и кружочки (до минуты), запись как в Telegram: удерживать, чтобы записать, отпустить, чтобы отправить, нажать, чтобы переключить, потянуть вверх, чтобы закрепить, влево, чтобы отменить.
- **Звонки:** аудио- и видеозвонки один на один через свой сервер-ретранслятор, камеру можно включить посреди звонка, звонок сворачивается, чтобы продолжать переписку, виден заряд батареи собеседника (если его браузер это сообщает), эффекты на лицо рисуются на устройстве (корона, ушки, сердечки, снег, цветные фильтры), восстановление связи при смене сети (Wi-Fi на мобильную) и индикатор качества связи.
- **Приложение:** push-уведомления (и в фоновой вкладке, и позади других окон; на звонок одно уведомление с кнопками «Ответить» и «Отклонить», потом «Пропущенный звонок», если не ответили; чат, прочитанный на одном устройстве, убирает уведомления на остальных в браузерах на Chromium), инструкция по настройке для каждой платформы и кнопка проверки в настройках, окно звонка поверх других окон (Chrome и Edge на компьютере), светлая и тёмная темы, русский и английский, размер текста, блокировка PIN-кодом или Face ID / отпечатком, скрытие статуса «в сети».
- **Небольшой сервер:** один исполняемый файл на Go с SQLite, ежедневные зашифрованные бэкапы (по желанию в S3), метрики Prometheus. Работает на VPS с 1 ГБ памяти.

## Быстрый старт

Нужен VPS с Ubuntu или Debian и домен, который на него указывает. Дальше:

```bash
git clone https://github.com/saifutdinov/thread.git && cd thread
sudo scripts/setup-server.sh                 # Docker, файрвол, обновления
sudo scripts/install.sh chat.example.org     # запуск, покажет первую ссылку-приглашение
```

Откройте показанную ссылку на телефоне, и вы первый участник. **Подробная инструкция со всеми шагами, портами, бэкапами и решением проблем: [scripts/README.ru.md](scripts/README.ru.md).**

## Безопасность: от чего защищает, а от чего нет

Нитка устроена так, чтобы ни сервер, который честно хранит и пересылает данные, ни хостер, ни тот, кто скопирует диск или бэкапы, не могли прочитать вашу переписку.

**Шифруется на устройствах:** текст сообщений, реакции, фото, видео, голосовые, файлы, названия групп, аватары и установка звонков. Ключи устройства не покидают его и не извлекаются даже самим приложением. Новое устройство получает доступ, только когда его одобрит одно из ваших устройств (а если вы потеряли все, собеседник после сверки кода с вами). Звонки WebRTC шифрует сквозным образом, ретранслятор видит только шифротекст.

**Видно серверу:** имена, кто в каком чате, когда отправлены сообщения и какого они размера, кто кому звонил и сколько длился звонок, IP-адреса, открыто ли приложение на переднем плане. С включённым предпросмотром ссылок сервер видит и ссылки, которые вы отправляете. **Видно другим:** push-сервисы (Apple, Google, Mozilla) видят, когда и на какое устройство уходит уведомление, но не его содержимое; при прямом звонке собеседники видят IP-адреса друг друга, как в любом звонке WebRTC.

**Честные ограничения:**

- Протокол шифрования - собственная разработка из стандартных примитивов WebCrypto (ECDH и ECDSA P-256, AES-256-GCM, HKDF). **Независимого аудита не было.** Людям, которым угрожает серьёзная опасность, лучше пользоваться Signal.
- **Активно вредоносный сервер может добавить устройство** в список устройств человека: новые ключи чатов тогда шифруются и для него, и оно сможет читать новые сообщения. Сверка кодов безопасности это покажет, предупреждением в вашем личном чате, но только после того, как вы коды сверили, и автоматически ничего не блокируется. Сверьте коды с самыми важными для вас людьми.
- Как у любого шифрования в браузере, код приложения приходит с сервера: взломанный сервер может отдать изменённый код. Строгая политика безопасности контента (CSP) и отсутствие сторонних скриптов снижают этот риск, но не убирают его.
- Внутри периода ключа нет прямой секретности (forward secrecy): утёкший ключ чата раскрывает сообщения этого периода. Ключи меняются раз в неделю и каждый раз, когда кто-то вступает, выходит или отключается устройство.

Протокол описан в [docs/adr/0001-e2ee-webcrypto.md](docs/adr/0001-e2ee-webcrypto.md), модель угроз и как сообщить об уязвимости - в [SECURITY.md](SECURITY.md) (на английском).

## Настройки

`scripts/install.sh` создаёт `.env` сам. Всё, что там можно указать:

| Переменная | Значение |
|---|---|
| `DOMAIN` | Домен чата, например `chat.example.org` |
| `PUBLIC_IP` | Публичный IPv4 сервера (для ретранслятора звонков) |
| `RELAY_IP` | Локальный IPv4, с которого работает ретранслятор; отличается от `PUBLIC_IP` только за NAT 1:1 (по умолчанию `PUBLIC_IP`) |
| `PASSWORD_PEPPER` | Секрет, который входит в хэш каждого пароля. **Никогда не меняйте и не теряйте.** |
| `TURN_SECRET` | Секрет для временных паролей ретранслятора звонков |
| `VAPID_SUBJECT` | Контакт для push-сервисов, `mailto:` или `https:` (по умолчанию адрес чата) |
| `BACKUP_RECIPIENT` | Открытые ключи age через запятую: включает ежедневные зашифрованные бэкапы |
| `BACKUP_KEEP` | Сколько локальных снимков хранить (7) |
| `BACKUP_S3_ENDPOINT`, `BACKUP_S3_REGION`, `BACKUP_S3_BUCKET`, `BACKUP_S3_ACCESS_KEY`, `BACKUP_S3_SECRET_KEY` | Необязательный S3-совместимый бакет для копий вне сервера |
| `METRICS_ADDR` | Например `:9095`: метрики Prometheus во внутренней сети Docker (`thread_http_responses_total`, `thread_push_total`, `thread_sockets`, `thread_backup_*`) |

После правки `.env` примените её: `sudo scripts/install.sh`.

## Разработка

Нужны Go и Node.js версий из [mise.toml](mise.toml).

```bash
go run ./cmd/thread                 # сервер на :8080, данные в ./data, отдаёт web/dist
cd web && npm ci && npm run dev     # веб-приложение с горячей перезагрузкой на :5173, API проксируется на :8080
go test -race ./...                 # тесты сервера
cd web && npm test                  # тесты шифрования, переводов и настройки звонков
```

При первом запуске с пустой базой сервер пишет в лог одноразовую ссылку для первого пользователя. Архитектура, модули и паттерны: [PROJECT_GRAPH.md](PROJECT_GRAPH.md). Правила для участников (и людей, и ИИ-агентов): [AGENTS.md](AGENTS.md).
